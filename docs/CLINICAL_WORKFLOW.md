# 투명교정 진료 흐름과 cuAlign의 위치

> 2026-09-24 치과 방문 메모와 제품별 공식 자료를 대조한 팀 설명 자료다. 방문한 치과의 작업 방식은 한 사례이며, 모든 치과의 표준 절차로 일반화하지 않는다. 제품 범위의 정본은 [PRD](PRD.md), 현재 구현의 정본은 [TRD](TRD.md)다.

## 진료에서 설계·제작까지

1. **초진과 자료 수집** — 의사가 문진·구강검사를 하고 방사선 영상, 안면·구강 사진 등 필요한 진단 자료를 모은다. 방문 메모에는 측모두부규격방사선사진(세팔로), 파노라마, 여러 방향의 사진이 기록돼 있다. CT/CBCT는 모든 케이스의 필수 입력으로 가정하지 않는다.
2. **계측·분석과 치료 결정** — 방문한 치과는 WebCeph의 자동 트레이싱을 의사가 조정해 계측·분석 보고서를 만들었다. 의사가 다른 진단 자료와 함께 발치 여부, IPR 허용 부위·범위, 확장 여부, 목표와 기간을 판단하고 환자와 상담·동의한다. WebCeph는 이 판단을 돕는 도구이지 cuAlign의 진단 단계가 아니다.
3. **구강 스캔과 디지털 셋업** — 상담 뒤 스캔을 얻고 치아를 분리해 현재 치열과 목표 배열을 다룬다. 관찰된 경로는 자료를 제조사에 보내 셋업·제작을 의뢰하는 방식과 원내에서 CAD 도구로 계획·제작을 진행하는 방식이다. DentOne은 후자의 예시이며 치아 분할, 치아별 목표 위치·IPR·고정 설정을 제공한다.
4. **스테이징과 검토** — 목표까지의 이동을 단계와 순서로 나누고, 단계별 치아 이동과 제약을 검토·수정한다. DentOne도 자동 단계 생성과 단계 편집을 제공한다. 따라서 “자동 스테이징 자체”는 cuAlign만의 기능이 아니다.
5. **제작과 경과 확인** — 선택한 계획의 단계별 파일을 제조 경로로 넘겨 장치를 제작하고, 의사가 환자의 진행을 추적하며 필요하면 계획을 다시 검토한다. 단계별 치아 STL, 출력용 모델, 직접 착용하는 장치 형상은 서로 다른 산출물이다.

## cuAlign이 맡는 일

**의사가 결정한 치료 제약 안에서 치아 이동의 전략·순서를 계획하고, 규칙 위반을 확인해 허용된 대안을 다시 만드는 작업**이 중심이다. 진단 결과 자체를 결정하거나 환자에게 치료를 처방하지 않는다.

`의사 진단·허용 범위 확정 → 분리된 치아 형상 입력 → 조건 확인 → 전략·단계 계획 → 계산 검증 → 의사 비교·수정 → 재계획 → 검토용 단계 결과`

- 입력 예: “발치하지 않음”, “이 치아는 고정”, “해당 치간 IPR 제외”, “계획상 12개월 이내”. 에이전트는 이 조건을 비교·수정 뒤에도 유지해야 한다.
- 계산과 대화: 허용된 이동 전략을 시도하고 공간 부족·겹침·이동량·단계 수 위반을 보여준다. 조건을 만족하는 안이 없으면 이유와 의사에게 필요한 판단을 표시한다.
- 의사 역할: 제약을 바꾸거나 안을 선택할지 결정한다. 에이전트가 금지 조건을 임의로 풀어 통과안을 만들지 않는다.
- 검증할 가치: 같은 사례에서 수작업 대비 계획·수정 반복 횟수와 소요 시간을 줄이는지 확인해야 한다. 아직 실측된 효과는 없다.

**예선 데모 경계:** 분리된 치아·합성 샘플로 위 반복을 보여주고 단계별 치아 STL을 낸다. 현재 계산은 상악 평행 이동 중심이며 임상적으로 타당한 치료계획이나 제조 가능한 장치 파일을 입증하지 않는다. 전체 제품 목표인 장치 형상 출력은 별도 기술 검토가 필요하다.

## 말할 때 구별할 것

| 표현 | 이 프로젝트에서의 뜻 |
|---|---|
| 진단·치료 결정 | 발치·IPR·확장 등 환자에게 필요한 처치를 의사가 판단하는 일 |
| 디지털 셋업 | 분리한 치아의 목표 위치와 조건을 다루는 CAD 작업 |
| 스테이징 | 목표까지 치아 이동을 단계·순서로 나누는 일 |
| 규칙 검증 | PoC에서 설정한 공간·충돌·이동량·단계 수 조건을 계산으로 확인하는 일. 임상 검증과 다름 |
| CAD/CAM | 설계와 제조 작업. 단계별 STL 생성만으로 장치 제작을 완료한 것은 아님 |
