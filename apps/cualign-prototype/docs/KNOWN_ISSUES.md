# 알려진 문제와 미완료 항목

> 2026-09-24 인수 기준. 개발 출발점의 상태를 알리는 문서이며 수정 완료를 뜻하지 않는다.
> 검증 환경·범위는 [VERIFICATION](VERIFICATION.md), 제품 요구사항은 [PRD](PRD.md)가 정본이다.

## 검토 에이전트 응답 형식 오류 — 미해결

**관측:** 팀 이관 코드 `0d02a29`의 Docker Linux arm64 환경에서 NIM 합성 케이스 1건을 실행했다.
계획 에이전트는 확장·IPR 실패 후 병행안을 규칙 통과시켰지만, reviewer에서 빈 응답에 따른 파싱 오류가 반복됐다.
도구 내부 재시도를 소진한 호출도 있었고, 상위 에이전트가 reviewer를 다시 호출한 뒤 검토 메모를 받았다.
전체 실행은 89.5초, 종료 코드 0이었다. 종료 코드만 보면 이 문제를 놓친다.

관측 오류 발췌:

```text
Tool call attempt 1/3 failed for tool reviewer: ReActAgentParsingFailedError
Invalid Format: Missing 'Action:' after 'Thought:'. LLM output: ''
Tool call failed after all retry attempts.
```

**영향:** 추가 모델 호출·응답 지연이 생기며 다음 실행에서도 복구된다는 보장이 없다.
워크플로 지시문의 “reviewer 한 번 호출”도 이 실행에서는 지켜지지 않았다.
계획 계산 성공과 검토 메모 생성 성공을 구별해야 한다. 현재 코드를 무오류·안정적인 시연 완성본으로 소개하지 않는다.

**원인:** 로그로 확인한 것은 빈 응답과 ReAct 파싱 실패다. 모델·NAT·프롬프트 중 근본 원인은 아직 분리하지 않았다.
기존 `react_patch.py`가 이 문제까지 해결한다고 가정하지 않는다.

**재현 요청:** `moderate 케이스로. 발치 없이 12개월 안에 끝나는 계획 짜줘. 앞니 총생부터 풀고.`
실행 당시 `configs/workflow.yml`의 기본 모델은 `nvidia/nemotron-3-super-120b-a12b`다.
키가 이미 프로세스 환경에 설정된 별도 로컬 환경에서 다음 CLI로 같은 입력 경로를 확인할 수 있다.
원격 사용량이 발생하며 확률적인 오류라 매번 동일하게 재현되지는 않는다. 이 CLI는 HTTP Guardrails를 거치지 않는다.

```sh
uv run nat run --config_file configs/workflow.yml --input "moderate 케이스로. 발치 없이 12개월 안에 끝나는 계획 짜줘. 앞니 총생부터 풀고."
```

**수정 시 확인:** 빈 응답·파싱 실패를 주입한 검사, 재시도 상한과 오류 표시, 최종 검토 메모의 생성 여부를 별도로 확인한다.
필요한 실호출을 승인된 사용량 안에서 수행하고 성공 결과뿐 아니라 재시도·실패도 기록한다.
파싱 복구는 검토 메모의 임상적 정확성을 보장하지 않는다.

## 개발·시연 전에 함께 볼 항목

| 항목 | 현재 상태·영향 | 상세·확인 기준 |
|---|---|---|
| 비교·수정의 조건 유지 | 공통 제약 객체가 없고 비교 도구는 고정·IPR 제외 입력을 받지 못함 | TRD §3–4. 조건이 계산·검증에 계속 반영되는지 검사 |
| 계획과 화면 연결 | UI가 스트림 텍스트에서 계획 ID 추출, 수정 계보 미정 | TRD §4. 선택한 계획·3D·파일 일치 검사 |
| 사용자·케이스 격리 | 프로세스 전역 활성 케이스·STORE 공유 | SECURITY. 동시 사용자 운영 전 격리 설계 필요 |
| Guardrails 오류 경로 | 검사 오류·타임아웃 때 진행 가능, 출력은 사후 검사 | TRD §5. 검사 불가 정책과 화면 표시 합의 필요 |
| 최신 통합 시나리오 | NIM CLI 1건과 브라우저 규칙 폴백은 각각 확인, UI 대화 통합 5건은 미확인 | VERIFICATION. 예선 시연 완료 판단 전에 통합 검사 |

세그먼테이션 추론·OpenShell 서버 통합·장치 셸 생성의 상태는 TRD §6 및 NVIDIA_STACK에서 관리한다.
이 문서에 문제를 적었다는 이유로 해당 기능을 완료 처리하지 않는다.
