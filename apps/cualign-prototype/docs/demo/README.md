# docs/demo — 실행 기록과 화면

이 폴더의 로그·요약·스크린샷은 **기록 당시 코드**의 실행 근거다. 지금 화면의 설명으로 쓰지 않는다.

| 묶음 | 내용 |
|---|---|
| `scenario-*.log`, `summary-*.md` | 다섯 시나리오 실호출 로그(`scripts/run_scenarios.py`) |
| `guardrails*.md` | Guardrails 범위 검사·오탐 확인 기록 |
| `scan-reveal/` | 셋업 턴 스캔 인식·처방 적용 연출(#161) |
| `stream-reasoning/` | 셋업 턴 추론 줄 실호출 1회(000097, 2026-09-28): 첫 추론 줄이 뜬 순간, 답 도착 뒤 접힌 모습 |
| `viewer-3d/` | 3D 뷰어 확인 화면 |
| `ui-*.jpg` | 2026-09-25 무렵의 옛 화면(합성 `moderate`·`severe` 케이스, 옛 대화 패널). 지금 화면과 다르다 |

## 제출용 화면 다시 찍기 (예정)

2026-09-28 에 UI 가 크게 바뀌어 `ui-*.jpg` 세 장은 옛 화면이다. 우측 탭 자동 전환·스캔 탭 치아 차트(right-scan)와
반응형·WebGL 폴백(responsive) PR 이 들어온 뒤 메인 세션이 마지막에 한 번에 찍는다. 아래는 찍을 장면과 상태다.

- 공통: 1600×1000 한 뷰포트, 샘플 케이스, 새로 띄운 서버(`CUALIGN_OUT` 빈 폴더). 에이전트 턴은 실호출이 되면 실호출,
  429 가 잦으면 재생(건너뛰기 → 녹화된 답)으로 찍고 어느 쪽인지 파일 이름이나 캡션에 적는다(재생은 말풍선에 「녹화된 답」 표시가 붙는다).
- `ui-interview-multiturn-live.jpg` 는 `guardrails.md` 가 그날 실측 근거로 가리키므로 덮어쓰지 않고, 새 파일 이름으로 찍는다.
