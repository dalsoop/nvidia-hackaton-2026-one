# Codex 작업 안내

먼저 `README.md`와 `CONTRIBUTING.md`를 읽는다. 제품 변경은 `docs/prd.md`, 기술 변경은 `docs/trd.md`, 파일 위치는 `docs/code-map.md`를 확인한다.
공통 개발·검증 규칙의 정본은 `CONTRIBUTING.md`다. 개인 홈 디렉터리의 스킬·도구·다른 레포를 전제하지 않는다.

- 수정 전에 `git status --short --branch`로 기존 변경을 확인하고 다른 작업자의 변경을 보존한다.
- 요청 범위만 수정한다. 제품 범위·공개 배포·보안 경계를 임의로 바꾸지 않는다. 미결정 사용자 동작은 확정 요구사항으로 취급하지 않으며, 가정을 명시한 실험과 최종 정책 결정을 구분한다.
- 명령·검증 결과를 확인하고 보고한다. 오프라인 테스트를 NIM 실호출·임상 검증으로 표현하지 않는다.
- 실제 키·환자 데이터는 읽어 출력하거나 커밋하지 않는다. 결과물은 초안이며 판단 주체는 의사다.
- 공통 규칙을 이 파일에 복제하지 않는다. 동작 변경은 해당 명세와 테스트에 함께 반영한다.
