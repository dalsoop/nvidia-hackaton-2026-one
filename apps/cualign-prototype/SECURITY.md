# 보안·안전 범위

cuAlign은 의사가 검토할 스테이징 초안을 만드는 연구용 PoC다. 임상 사용의 적합성이나 규제상 분류를 검증한 제품이 아니다.

- **운영 범위:** 사용자 인증·사용자별 저장소 격리가 없다. 계획과 활성 케이스가 프로세스 전역으로 공유된다. 로컬 시연에서는 `--host 127.0.0.1`을 사용한다.
- **입력:** 기본 데모는 합성 배치 데이터다. 업로드 파일 크기·악성 형상·메모리 사용에 대한 운영 수준의 방어는 검증하지 않았다. 신뢰할 수 없는 네트워크에 노출하지 않는다.
- **외부 전송:** 현재 메시 계산은 로컬에서 수행한다. 대화·도구 결과 요약은 설정된 모델 엔드포인트로 전달될 수 있다. 환자 식별 정보를 대화에 넣지 않는다. 레일이 켜져 있으면 주민등록번호·휴대전화·이메일 꼴은 모델 전에 거절하지만, 이름·차트 번호와 폴더 이름에 든 다른 꼴은 잡지 않는다. 웹 UI는 외부 CDN의 three.js를 불러온다.
- **저장:** 업로드와 계획 출력은 `out/` 또는 `CUALIGN_OUT` 지정 위치에 남는다. 자동 삭제·보존 기간 관리·암호화·재시작 복원은 제공하지 않는다.
- **Guardrails:** 활성화되면 에이전트를 부르는 모든 경로(`nat serve` 대화·생성 경로 전부, `nat run`, 평가 실행기)에서 입력 범위 검사와 출력 검사를 수행한다. 답은 출력 판정까지 내보내지 않고, 막히면 거절문으로 바꾼다. 진행 표시는 도구 이름·인자만 남긴다(도구 결과·모델 글은 나가지 않는다 — 워커가 도구 끝 단계를 결과 없이 다시 만들고, 요청 원문을 되돌려 보내는 워크플로 시작·끝 단계는 뺀다). `/v1/workflow/full`·`/generate/full`·`/v1/workflow/atif` 의 원 단계는 거르지 않는다. 검사 오류·타임아웃 시 ERROR 로그를 남기고 진행할 수 있다. 꺼져 있으면 시작 때 ERROR 로그를 남긴다. `CUALIGN_RAILS_FAIL_CLOSED=1`이면 키 없이 시작하지 않고 검사 오류 턴을 거절한다. 일반 계산 API·다운로드는 같은 검사 경로가 아니다.
- **OpenShell:** 저장소의 정책은 별도 실험 자산이다. 현재 서버 전체를 샌드박스로 격리하는 실행 설정은 아니다.
- **SkillSpector:** 보고서는 검사 당시 Skill 스냅샷에 대한 결과다. 현재 서비스 전체의 보안 인증이 아니다.
- **보고:** 재현 절차에는 합성 데이터와 비밀을 제거한 로그만 사용한다. 민감한 취약점·키·환자 정보는 공개 이슈에 올리지 말고 저장소 관리자에게 비공개 연락한다.
