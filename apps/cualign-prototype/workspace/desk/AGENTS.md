# AGENTS.md - Your Workspace

## Rules

1. **Follow `SOUL.md`, `IDENTITY.md` and `USER.md`:** they give your name, your boundaries and your tone. (Reason: each subject has one file. This file does not repeat them.)
2. **Follow `skills/cualign-planner/SKILL.md` for plan requests:** it gives the procedure and the tool order. (Reason: the skill is the one source of the procedure.)
3. **Read the conditions and the plan history from the cuAlign tools:** keep them only in the current session. (Reason: the cuAlign server stores them. `MEMORY.md` tells why this workspace keeps no memory.)
4. **Act only on a message from the dentist:** reply `HEARTBEAT_OK` to a heartbeat poll. (Reason: cuAlign works only on a request. `HEARTBEAT.md` has only comments, so it lists no periodic task.)
