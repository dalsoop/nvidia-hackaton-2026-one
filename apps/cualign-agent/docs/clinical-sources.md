## 참고 문헌과 확인 수준

- [Applied Sciences 2024 리뷰](https://www.mdpi.com/2076-3417/14/15/6690): 기존 2026-09-22 조사에서 이동·각도 관련 참고로 사용. 2026-09-24 재접근은 HTTP 429로 본문 재대조 실패.
- [IJOS 2025 전문가 합의](https://www.nature.com/articles/s41368-025-00350-2): 기존 2026-09-22 조사에서 공간 확보 관련 참고로 사용. 2026-09-24 재접근은 인증 리다이렉트로 본문 재대조 실패. 위 개별 설정값을 보편적 한계로 확정하지 않는다.
- [Align Technology의 1주 착용 안내](https://investor.aligntech.com/news-releases/news-release-details/align-technology-introduces-one-week-aligner-wear-invisalignr): 2016년 특정 Invisalign 제품에 관한 제조사 안내. 의사의 재량과 환자 반응에 따른 더 긴 착용 가능성을 명시한다. 접근 2026-09-24. 모든 장치·환자에게 일반화하지 않는다.
